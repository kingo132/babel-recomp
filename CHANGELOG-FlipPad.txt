FlipPad source version history

0.3.3 — 2026-11-03
Do not advance HDMA during the PPU's non-visible line-zero initialization.
This restores the last scanline of Chinese inventory glyphs and aligns raster
windows with an independent native renderer. Keep Android's FlipPad input under
the platform driver by disabling SDL raw HIDAPI access, preserving system diamond
navigation. Physical-main-display regressions use copies of user progress.

0.3.2 — 2026-11-03
Shared display rules with the two Quintet hosts: OAM-first opaque selection,
9-bit OBJ name-bank and row/column wrapping, windows and scroll unwrapping.
Read dynamic actor source graphics through the game's streaming table rather
than interpreting their source tile IDs as static VRAM; restore depth buckets
and palette flashing without changing actor scripts or offscreen game logic.
Qualify full maps against the native VRAM ring, reset per-frame raster validity,
and retain the top HUD on native-view fallback. Add opt-in desktop reconstruction
audits and shared-rule CI tests. Existing CN package and progress are preserved.

0.3.1 — 2026-11-03
Android 17/API37 target and build chain; adaptive/round/monochrome original
vector launcher artwork; system splash and modern Back/insets integration.
Chinese edition becomes the default build and retains local.gaia.flippad.cn.
Add ROM-free Android CI and record preserved source snapshots in Git.

0.3.0 — preserved source snapshot imported 2026-11-03
Japanese Chinese V1 ROM identity and player-global layout; independent saves.
Repair BG3 HUD extraction cutting dialogue, show assistant version, and prefer
OpenSL ES after Pixel 9 AAudio route-disconnect failures.

0.2.1 — preserved source snapshot imported 2026-11-03
True portrait world rendering and FlipPad assistant/saves/speeds/filters.
Fix fine-scroll seam, BG2 character page and colour math; integer auto-fit.

0.1.0 — preserved source snapshot imported 2026-11-03
Initial portrait Android package and independent background suspend state.
This version predates the requested expanded-world layout and is historical.

Tags identify source snapshots. ROM-bearing local APKs and personal data are
never included in the public fork or its releases. Tests cover early scenes
and narrow regressions, not a complete playthrough.
